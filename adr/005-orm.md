# 005 — ORM choice

**Date:** 2026-03-31
**Status:** Under discussion — to be decided at implementation start

## Context

The project needs database access with TypeScript support and a migration story.

## Decision

TBD. Update when decided.

## Options

- **Prisma** — excellent DX, type-safe generated client, good migration tooling.
  Best choice if prioritizing developer experience and code clarity.
- **TypeORM** — pairs well with NestJS, decorator-based, familiar to Java/Spring developers.
  More verbose but integrates naturally if NestJS is chosen ([ADR 003](003-backend-framework.md)).
- **Knex** — query builder, not a full ORM; maximum control, minimum magic.

## Recommendation

Prisma if using Express; TypeORM if using NestJS.
